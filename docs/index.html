About RISA-16

The motivation behind this was to make a virtual machine for educational purposes — to play around with, have fun with, and learn how these things work. RISA-16 is a simple 16-bit ISA with 16 general-purpose registers, a small memory space, and a handful of instructions to keep things approachable.
